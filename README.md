# analyst-skills

Репозиторий навыков аналитической команды для Claude Code и Cowork. Репозиторий устроен как plugin marketplace: команда подключает его одной командой и ставит нужные наборы.

## Установка

```bash
# добавить маркетплейс (для приватного репозитория нужен gh auth login)
/plugin marketplace add ZlatikObr/analyst-skills

# поставить наборы
/plugin install ru-research-writing@analyst-skills
/plugin install equity-research@analyst-skills
```

Обновление после изменений в репозитории:

```bash
/plugin marketplace update analyst-skills
```

Подключить для всей команды на уровне проекта, а не пользователя:

```bash
claude plugin marketplace add ZlatikObr/analyst-skills --scope project
```

## Что внутри

### ru-research-writing

| Навык | Что делает |
|---|---|
| `russian-final-style` | Русский стиль исследовательских отчетов: тезис в начале абзаца, запрет длинных тире, буквы ё, конструкции «не X, а Y» и нейросетевых усилителей |
| `inline-sources` | Ссылка ставится на утверждении внутри предложения, каждое число помечается как замер, расчет, оценка или допущение |
| `sopostavimost` | Проверка сопоставимости по пяти осям перед любым множителем, процентом разницы или утверждением «X больше Y» |
| `check-before-send` | Обязательная проверка перед выдачей файла с расчетами: воспроизвести производные числа, сверить суммы частей с итогом, назвать свежесть данных |

### equity-research

| Навык | Что делает |
|---|---|
| `minto-storyline` | Сторилайн как дерево тезисов по Минто, протокол проверки веток на MECE, правила обращения с цифрами, раскладка в 6-pager |
| `zlata-viz` | Графики для отчетов: чистый inline SVG без внешних библиотек, геометрическая проверка подписей кодом |

Агент `ru-equity-investor` рецензирует инвестиционные материалы в роли частного инвестора, торгующего на Московской бирже. Вызывается как `@equity-research:ru-equity-investor`.

## Структура репозитория

```
.claude-plugin/
  marketplace.json          каталог наборов
plugins/
  <plugin-name>/
    .claude-plugin/
      plugin.json           метаданные набора
    skills/
      <skill-name>/
        SKILL.md            сам навык
        reference.md        опционально, крупные справочники
        scripts/            опционально, исполняемые скрипты
    agents/
      <agent-name>.md       опционально, субагенты
```

Правила именования: `name` навыка и набора в нижнем регистре через дефис, без пробелов и двоеточий. Имя папки навыка совпадает с полем `name` в SKILL.md.

## Что в репозиторий не кладется

1. Финансовые модели, выгрузки, клиентские данные и любые рабочие файлы проектов. Репозиторий содержит только методологию.
2. Токены, ключи API, ссылки на внутренние системы с доступом.
3. Навыки чужого авторства без разрешения автора и без указания лицензии.

## Как добавить навык

1. Создать папку `plugins/<набор>/skills/<имя-навыка>/` и в ней `SKILL.md`.
2. Заполнить frontmatter: `name` и `description`. В `description` написать, когда навык применять, и включить слова-триггеры, по которым модель его подхватит.
3. Держать SKILL.md короче 500 строк. Крупные справочники выносить в `reference.md` и ссылаться на них из SKILL.md относительной ссылкой.
4. На файлы внутри навыка ссылаться через `${CLAUDE_SKILL_DIR}`, чтобы навык не зависел от текущей папки.
5. Поднять `version` в `plugin.json` и в `marketplace.json`.
6. Открыть pull request. Прямые коммиты в `main` закрыты.

## Проверка перед pull request

- `SKILL.md` есть в каждой папке навыка, `name` совпадает с именем папки.
- `marketplace.json` и все `plugin.json` проходят проверку синтаксиса JSON.
- В диффе нет данных клиентов, ключей и рабочих файлов.
