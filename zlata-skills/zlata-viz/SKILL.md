# Визуализация для исследовательских отчётов

Графики идут картинкой в текстовый документ. Из этого следует всё остальное.

## Жёсткие запреты

- **Никаких внешних библиотек и CDN.** Chart.js, D3, Plotly с CDN запрещены: при недоступности сети получается пустое поле вместо графика. Только чистый inline SVG, отрисованный собственным кодом.
- **Никакой информации, доступной только по наведению курсора.** Все значения подписаны прямо на графике. Тултипы допустимы как дополнение, но не как единственный носитель числа.
- **Никаких презентаций по умолчанию.** Формат вывода — HTML-страница со скроллом, а не слайды 16:9. Слайды делать только по явной просьбе.
- **Цифры не выделяются цветом.** Цветом заливаются шапки таблиц и полосы графиков. Числа остаются нейтральными.
- **Никаких эмодзи.**

## Обязательная геометрическая проверка

Перед выдачей файла прогнать в коде проверку каждой подписи:

1. Для каждого текстового элемента вычислить координату начала и конца с учётом длины строки (примерно 6–7 px на символ при размере 12–13).
2. Сверить, что подпись помещается в viewBox и не выходит за поле.
3. Сверить, что подписи соседних элементов не пересекаются: ни по горизонтали в одной строке, ни по вертикали в соседних.
4. Отдельно проверить: подписи столбиков против осевых подписей, подписи значений против названий категорий, самый длинный текст против ширины отведённой колонки.
5. Вывести результат проверки в консоль и показать пользователю.

Наложение подписей — самая частая претензия. Оно ловится расчётом, а не глазами.

При большом числе точек использовать автоматическое разведение: перебор направлений вокруг точки с растущим радиусом, либо выноски-сноски (подчёркнутое название плюс линия к маркеру) светло-серым цветом.

## Палитра

```
Акцент, ссылки, ключевые числа   #0468ff
Голубой: заливка / текст          #a6c8f7 / #0b4a9e   светлая шапка #dfeafd
Зелёный: заливка / текст          #bcdc9b / #37701a   светлая шапка #e6f2da
Серый:   заливка / текст          #c3c9d3 / #5b6472   светлая шапка #eceef1
Отрицательные значения            #b42318   Предупреждения #b45309
Текст #1a1a2e   Приглушённый #6b7280   Линии #eef0f3
```

Заливка светлая, текст на ней тёмный. Белый текст на насыщенной заливке не использовать.

## Каркас страницы

```
body     Montserrat, фон #f6f7f9, padding 24px 28px 44px
h1       21px / 700      h2  15px, margin 26px 0 0
.sub     13px #6b7280, max-width 1010px, line-height 1.55
.card    белая, radius 12, тень 0 1px 4px rgba(0,0,0,.09), padding 18px 20px
.note    11.5px #6b7280 — оговорки и методология
.chk     фон #f0f7ff, рамка #cfe3ff, текст #1e3a5f — сходимость и подтверждения
.flag    фон #fef3f2, рамка #fecdca — ошибки и противоречия
.warn    фон #fffbeb, рамка #fde68a — ограничения данных
.lead    белая с левой полосой 4px акцентом — главный вывод, сразу под заголовком
.kpis    grid 4 колонки — крупные числа с подписью и пояснением
```

Структура: заголовок → подзаголовок с рамкой исследования → главный вывод в `.lead` → KPI-карточки → разделы, у каждого график или таблица плюс блок вывода → источники внизу мелким серым.

## Заголовки разделов

Заголовок формулирует вывод, а не тему. «Циан проигрывает не покупателя, а инвентарь» вместо «Анализ охвата площадок».

## Таблицы

- Числа выравнивать по правому краю или по центру, текст по левому, `font-variant-numeric: tabular-nums`
- Условное форматирование: полоса длиной пропорционально величине внутри столбца (фон #e4edfb), заливка ячейки с прозрачностью пропорционально модулю изменения — зелёная для роста, красная для падения
- Пустые ячейки помечать курсивом «не публикуется», а не прочерком: это разные вещи

## Экспорт под A4

По запросу выдавать SVG шириной 170 мм с размерами в мм и PNG 300 dpi. Проверять, что при пересчёте в миллиметры подписи не сливаются.

## Проверка перед выдачей

```
1. node --check по извлечённому JS — синтаксис
2. Баланс тегов отдельно в статическом HTML и в шаблонных строках внутри JS
3. Число колонок в шапке равно числу ячеек в строках, с учётом colspan
4. Геометрия всех подписей (см. выше)
5. Арифметика: воспроизвести каждое число графика из исходных данных
```
